# Which board carries the out-of-tree package gate for each KICKOS_ARCH.
#
# The gate installs the package and builds examples/oot-*-app against it from outside the
# tree (docs/reference/architecture.md states why this is the tree's one such reader). This
# file maps each KICKOS_ARCH to the board that carries its gate. Keyed on the ARCH and not on
# the family: KICKOS_ARCH_INCLUDE_DIR is per-arch, so a header that ships for armv6m alone is
# in no other arch's package.
#
# Read by tests/integration/gates/selftest.cmake, which registers the gate on the named board
# and nowhere else, and fails the configure of a board whose arch has no row, more than one, or
# a covers board that states another arch or that no configure preset sets, and every configure
# given a row whose arch no board states.
#
#   covers   <arch> <board>   the board whose preset runs the gate
#   declines <arch> <reason>  an arch no package can be consumed on yet, and why
#
# The boards are the emulated one of their arch where there is one, so a CI job already
# builds the preset.
#
# A `covers` row names the board that RUNS the gate, not that CI runs it: on rxv3 it is
# witnessed on a developer box alone.
