# Every program a CTest entry in this tree runs, and whether running it EXECUTES A KICKOS
# IMAGE. tests/static/check_test_labels.sh reads this and requires the `host` label on
# exactly the image=no set, in both directions.
#
#   <host|image>  <src|build>  <path relative to that root>
#
# host  = executes no KickOS image: source-tree checks, host programs linking KickOS sources
#         or headers, static checks reading a built ELF, and builds that never run what they
#         produced. Reads no clock, so `ctest -L host` is batchable.
# image = runs a KickOS image, natively or under an emulator, directly or through a tree it
#         configures and builds itself. Must run standalone: the sim and qemu suites have no
#         silicon clock and fail under the load of a back-to-back run.
#
# Neither the directory nor the argument list discriminates the two: check_oot_export.sh and
# check_oot_export_mcu.sh are siblings with the same shape on opposite sides. A new test gets
# a line here or the gate refuses it.
#
# A `build` path is relative to the CMake binary directory. A dead `build` line is caught on
# a sim tree with the host unit binaries built, which is the configuration that registers
# them.
