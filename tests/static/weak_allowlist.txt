# Every symbol KickOS is allowed to leave WEAK. tests/static/check_seam_defaults.sh (leg 4)
# fails the build on any other weak symbol, in any archive or in the image. No entry below may
# be a backend seam: those are resolved by archive-member extraction (arch/CMakeLists.txt).
#
# One symbol per line; the RX psABI prefixes C identifiers with an underscore, so a
# KickOS-owned entry is listed in both spellings.

# --- libc interop: weak so a libc providing them wins -------------------------
# The C++ ABI's per-DSO handle.
__dso_handle
___dso_handle
# newlib's malloc re-entrancy hooks; KickOS supplies no-ops.

___malloc_lock

___malloc_unlock

# --- hand-rolled vague linkage -----------------------------------------------
# kickos/app.h defines the per-app build stamp inline and the build force-includes that header
# into every app TU, so weak is what merges the duplicates; C has no COMDAT. The kernel's
# matching weak REFERENCE is what lets a link with no app TU at all resolve to null.
kickos_app_build_time
_kickos_app_build_time

# --- optional-symbol references (weak undefined, absence is legal) ------------
# The image's own layout bounds are NOT here. They are strong references against a window
# every linker script states, empty where it carves none (include/kickos/klink.h,
# arch/common/sections.ld.h), so a script that omits one fails the link.
#
# libgcc's unwinder registration, called by the RISC-V chip bring-up only when the link
# supplied it. Optional by libgcc's contract and not by ours, so no script can state it.
__register_frame
___register_frame
