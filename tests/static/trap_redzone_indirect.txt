# Per-call-site resolution of every indirect call a static callgraph walk goes through. TWO
# gates read it: tests/static/trap_redzone.py, which measures the trap-path stack descent, and
# tests/static/console_reach.py, which asks whether the fault-record console route can reach a
# panic.
#
# gcc's -fcallgraph-info emits one edge to the literal node `__indirect_call` per site and
# nothing more, so the depth through a site is whatever this file says.
#
# THE KEY IS A CALLER AND AN ORDINAL. `<caller>@<n>/<count>` is the n'th of the <count> indirect
# calls that caller makes, ranked by the basename, line and column gcc gave them. No source line
# is part of it, so an edit above a bound call leaves it alone; what moves an ordinal is that
# caller gaining or losing an indirect call, and <count> then disagrees with the graph and every
# record of that caller is refused at once.
#
# THREE FAILURES, KEPT APART ON PURPOSE:
#   UNBOUND INDIRECT SITE   a site reachable from a root that no record here names.
#   ABSENT CALLEE           a record whose named callee is not in the graph.
#   KEY DOES NOT RESOLVE    a record whose caller is gone, names two nodes, or no longer makes
#                           <count> indirect calls.
# All three are HARD FAILURES, and the third is never answered by renumbering an ordinal: a
# moved count means every ordinal in that body moved, so renumbering would charge a measured
# callee to a call that does not make it. Re-read the body and re-declare its sites.
#
# File format, one record per line, '#' starts a comment, a trailing '\' continues:
#   site <arch> <scope> <caller>@<n>/<count> <callee>...
#   site <arch> <scope> <caller>@<n>/<count> NONE
#   site <arch> <scope> <caller>@indirect <callee>...
# The third form is for a caller whose indirect edges gcc emitted with NO location at all: it
# stands for every one of them at once, so a body carrying one has to be re-read by hand when
# it changes. <scope> is a configure-preset name, or '*' for every preset of the arch. A record
# out of scope is not read at all. NONE declares a site with no reachable callee AT ALL; the
# tool accepts it and charges 0.
#
# A <caller> and a <callee> are named the same way: a bare global symbol, a demangled name
# carrying '::', or `<basename>:<name>` for a file-scoped one, where <name> is that function's
# own identifier or its whole mangled tail. EVERY MATCH IS EXACT and must be UNIQUE; naming a
# function by its identifier rather than its tail is what covers the two toolchains spelling
# internal linkage differently, one emitting an L before the name length and the other not. A
# '?' before a callee marks it OPTIONAL: compiled out under some option, so its absence is not
# a stale binding.
#
# ONE SOURCE LINE CAN CARRY SEVERAL SITES: an inlined body puts its indirect call into each of
# its callers, and each of those is a call of its own with a caller and an ordinal of its own.
