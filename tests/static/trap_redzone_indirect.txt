# Per-call-site resolution of every indirect call the trap-path measurement walks through.
#
# WHY PER SITE AND NOT PER POINTER. gcc's -fcallgraph-info emits one edge to the literal
# node `__indirect_call` per site, and nothing more, so the depth through it is whatever
# this file says it is. Charging a site the maximum over the UNION of everything the
# pointer's type could hold invents paths that do not exist: the SchedPolicy table below
# would then let sched::reschedule reach policy_on_ready, which queues and can reschedule,
# and the tool would report a cycle through the scheduler that the deferred rv32imac/rxv3
# arch_switch cannot take. Each site is bound to the ONE slot the source at that line
# calls, so the depth is the depth of the real edge.
#
# An indirect site reachable from a root and NOT declared here is a HARD FAILURE, because
# an unbound site makes the whole figure a lower bound rather than a bound. A declaration
# whose site or whose named callee is not in the graph is a hard failure too: a stale
# binding rots exactly the way a stale margin does.
#
# FILE FORMAT, one record per line, '#' starts a comment, a trailing '\' continues:
#   site <arch> <scope> <basename>:<line>:<col> <callee>...
#   site <arch> <scope> <basename>:<line>:<col> NONE
# <scope> is a configure-preset name, or '*' for every preset of the arch. A record out of
# scope is not read at all, which is how one arch carries two boards with different
# backends. NONE declares a site with no reachable callee AT ALL; the tool accepts it and
# charges 0, and it is deliberately not the same thing as an omitted record.
#
# A <callee> is either a bare global symbol, or `<basename>:<needle>` for a file-scoped
# one, where <needle> must appear in the mangled tail and the match must be UNIQUE. The
# needle form is there because the two toolchains in this fleet do not spell internal
# linkage the same way: riscv32-none-elf-gcc 16 emits
# _ZN6kickos12_GLOBAL__N_1L15policy_on_readyEPNS_6ThreadE and rx-elf-gcc 14.2 emits the
# same name without the L. A '?' before a callee marks it OPTIONAL: compiled out under
# some option, so absent from the graph is not a stale binding.
