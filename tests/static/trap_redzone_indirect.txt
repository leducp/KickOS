# Per-call-site resolution of every indirect call a static callgraph walk goes through. TWO
# gates read it: tests/static/trap_redzone.py, which measures the trap-path stack descent, and
# tests/static/console_reach.py, which asks whether the fault-record console route can reach a
# panic.
#
# gcc's -fcallgraph-info emits one edge to the literal node `__indirect_call` per site and
# nothing more, so the depth through a site is whatever this file says.
#
# An indirect site reachable from a root and NOT declared here is a HARD FAILURE. A declaration
# whose site or whose named callee is not in the graph is a hard failure too.
#
# THE LINE NUMBERS BELOW ARE LOAD-BEARING IN THE SOURCE, NOT ONLY HERE. Deleting a
# comment, rewrapping one, or adding an #include above a bound site shifts it, and every
# binding into that file goes stale at once. Derive the bound basenames before touching any of
# them:
#   grep -oE '[A-Za-z0-9_.-]+[.]cc:[0-9]+:[0-9]+' <this file> | cut -d: -f1 | sort -u
# Re-take the bindings in the same commit that moves the lines, mapping old line to new with
# difflib over the two versions of the source; a column moves only under a reindent.
#
# File format, one record per line, '#' starts a comment, a trailing '\' continues:
#   site <arch> <scope> <basename>:<line>:<col> <callee>...
#   site <arch> <scope> <basename>:<line>:<col> NONE
# <scope> is a configure-preset name, or '*' for every preset of the arch. A record out of
# scope is not read at all. NONE declares a site with no reachable callee AT ALL; the tool
# accepts it and charges 0.
#
# A <callee> is either a bare global symbol, or `<basename>:<needle>` for a file-scoped one,
# where <needle> must appear in the mangled tail and the match must be UNIQUE. The needle form
# covers the two toolchains spelling internal linkage differently: one emits an L before the
# name length, the other does not. A '?' before a callee marks it OPTIONAL: compiled out under
# some option, so its absence is not a stale binding.
