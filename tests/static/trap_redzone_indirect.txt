# Per-call-site resolution of every indirect call the trap-path measurement walks through.
#
# WHY PER SITE AND NOT PER POINTER. gcc's -fcallgraph-info emits one edge to the literal
# node `__indirect_call` per site and nothing more, so the depth through it is whatever this
# file says. Charging a site the maximum over the UNION of everything the pointer's type could
# hold invents paths that do not exist: the SchedPolicy table below would then let
# sched::reschedule reach policy_on_ready, which queues and can reschedule, and the tool would
# report a cycle through the scheduler that the deferred rv32imac/rxv3 arch_switch cannot take.
#
# An indirect site reachable from a root and NOT declared here is a HARD FAILURE, because
# an unbound site makes the whole figure a lower bound rather than a bound. A declaration
# whose site or whose named callee is not in the graph is a hard failure too: a stale
# binding rots exactly the way a stale margin does.
#
# WHICH MAKES THE LINE NUMBERS BELOW LOAD-BEARING IN THE SOURCE AND NOT ONLY HERE. Deleting a
# comment, rewrapping one, or adding an #include above a bound site shifts it, and every
# binding into that file goes stale at once. Six basenames are bound today: sched.cc, irq.cc,
# console_tx.cc, syscall_ipc_fast.cc, chip_rp2040.cc, chip_rp2350.cc. Derive the set before
# touching any of them rather than trusting that list:
#   grep -oE '[A-Za-z0-9_.-]+[.]cc:[0-9]+:[0-9]+' <this file> | cut -d: -f1 | sort -u
# Re-take the bindings in the same commit that moves the lines, mapping old line to new with
# difflib over the two versions of the source; a column moves only under a reindent.
#
# FILE FORMAT, one record per line, '#' starts a comment, a trailing '\' continues:
#   site <arch> <scope> <basename>:<line>:<col> <callee>...
#   site <arch> <scope> <basename>:<line>:<col> NONE
# <scope> is a configure-preset name, or '*' for every preset of the arch. A record out of
# scope is not read at all, which is how one arch carries two boards with different
# backends. NONE declares a site with no reachable callee AT ALL; the tool accepts it and
# charges 0, and it is deliberately not the same thing as an omitted record.
#
# A <callee> is either a bare global symbol, or `<basename>:<needle>` for a file-scoped one,
# where <needle> must appear in the mangled tail and the match must be UNIQUE. The needle form
# exists because the two toolchains spell internal linkage differently: riscv32-none-elf-gcc 16
# emits _ZN6kickos12_GLOBAL__N_1L15policy_on_readyEPNS_6ThreadE where rx-elf-gcc 14.2 emits the
# same name without the L. A '?' before a callee marks it OPTIONAL: compiled out under some
# option, so absent from the graph is not a stale binding.
