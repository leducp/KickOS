# Indirect-call targets used by trap_redzone.py and console_reach.py.
# GCC callgraphs name only __indirect_call, so these records supply targets.
#
# Format (# starts a comment; a trailing backslash continues a record):
#   site <arch> <scope> <caller>@<n>/<count> <callee>...
#   site <arch> <scope> <caller>@<n>/<count> NONE
#   site <arch> <scope> <caller>@indirect <callee>...
#
# Number sites by GCC basename, line, and column within each caller. count
# is the caller's total indirect sites. If it changes, inspect all sites again;
# do not simply renumber. @indirect covers all sites without GCC locations
# and requires manual review when the caller changes. Inlining creates a
# separate site in each caller.
#
# Scope is a preset, * for the architecture, or cores=1 / cores>1 for every
# preset of the architecture whose kernel schedules one core / more than one:
# a call made only above one core moves its caller's count. NONE declares no reachable
# target and contributes zero stack use. Prefix optional callees with ?.
# Names must match uniquely: global symbols, demangled C++ names, or
# <basename>:<identifier-or-mangled-tail> for file-local functions.
# Missing site bindings, required callees, or unresolvable keys are errors.
