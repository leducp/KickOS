# Declarations for tests/static/check_trap_redzone.sh: WHICH symbols a trap prologue can reach,
# WHICH macro holds the figure it enforces, and WHAT the graph is allowed not to know. The macro
# names are resolved through the compiler under the flags the image was built with.
#
# A CLASS is one (FRAME, DEPTH) pair with its own root set. A trap prologue reserves FRAME plus
# DEPTH at the bottom of the interrupted stack and refuses the trap when less room than that
# remains below sp. DEPTH is the half this gate MEASURES, the worst-case bytes the kernel C
# dispatch descends on that same stack; FRAME is everything else in the zone, which on armv7m
# also carries the hardware frame a preempting exception stacks and no call graph can see.
#
# The classes live in the arch's trap-stack header beside the figures they enforce, one line of
# a comment each, and every KICKOS_*DEPTH* macro the header defines must be some class's depth:
#   class <CLASS> frame=<MACRO> depth=<MACRO> [stack=trap|stack=kernel|stack=panic|stack=idle] \
#                                               [kstacks=0|kstacks=1] [at=<symbol>]
#   class <CLASS> frame=<MACRO> depth=<MACRO> stack=main [size=<MACRO>] [core=secondary]
#
# File format, one record per line, '#' starts a comment:
#   arch    <arch> header=<path-relative-to-source-dir>
#   root    <arch> <CLASS> [?]<symbol> [level=<name>]
#   root    <arch> <CLASS> NONE reason: <text to end of line>
#   level   <arch> <CLASS> <name> reason: <text to end of line>
#   table   <arch> [?]<symbol> [first=<n>] [prefix=<p>] reason: <text to end of line>
#   vector  <arch> <handler> level=<name>|NONE reason: <text to end of line>
#   init    <arch> <start symbol> <end symbol> reason: <text to end of line>
#   exclude <arch> <mangled-symbol> [class=<CLASS>[,<CLASS>]...] reason: <text to end of line>
#   unsized <arch> <symbol> <bytes> [cores=1|cores>1] [calls=[?]<symbol>[,[?]<symbol>]...] \
#                                                        reason: <text to end of line>
#   recurse <arch> <symbol> <activations> reason: <text to end of line>
#   link    <arch> maps=<glob under the build directory> reason: <text to end of line>
#   asmcall <arch> <symbol> reason: <text to end of line>
#
# An unsized record with a scope is charged only to presets whose kernel schedules one core, or
# more than one; a symbol has at most one record per posture. Its calls= are the only edges an
# assembly body has, so a callee without '?' that the graph lacks is refused.
#
# An exclude with class= cuts the node from those classes' walks on whatever stack they spend:
# it claims the node unreachable under what those classes measure. Without class= it applies to
# every thread-stack class and to no other.
#
# A recurse record bounds a function's call to ITSELF: its frame is charged <activations> times
# and the self-edge is not walked. A record whose node has no self-edge is refused as stale.
#
# Every C function the assembly under the arch family's directory names, call or address, the
# arch's own and its chips' alike, read as this image's compile commands preprocess it with every
# file it includes, must be a root of some class, a calls= callee of an unsized body some class
# reaches, or carry a vector record; an asmcall record instead says no trap reaches it, and its
# reason names the stack it runs on. One that is also priced, or that no branch of the assembly
# names any more, is refused. The check is per function: which site a root or an edge stands for
# is the reader's to keep honest. Assembly outside arch/ is the user runtime's and is not read.
#
# A link record narrows the corpus to the units the matching link maps LOAD: an object a LOAD
# line names, or a member of a LOADed archive, the archive a target writes beside its CMakeFiles
# directory. A map counts only beside a file the build graph links. A glob matching no such map,
# or a map with no LOAD line, is refused.
#
# A '?' before a root or an `exclude` marks it OPTIONAL: the symbol is compiled out under some
# option, or absent from some boards' graphs, so its absence contributes 0 instead of failing.
# A root with no '?' that is missing is a hard failure. A '?' exclusion the graph does not have
# is reported as unused.
#
# NONE declares that the class runs NO C on the guarded stack, so its depth is 0 and there is
# nothing to walk. A class with no record at all is refused: an empty root set measures 0 and
# passes forever.
#
# A `root` symbol matches the graph as an exact name or as the mangled tail of a file-scoped
# one; the match must be UNIQUE, and an ambiguous name is refused rather than guessed at.
#
# The top-level CMakeLists registers the gate on every preset of an arch that has a trap-stack
# header: KICKOS_TELEMETRY, the memory model and the console backend each move a chain, and a
# board's variants differ by those.
#
# lx6 carries two thread-stack classes, PREEMPT and the unhandled-exception reporter's FAULT:
# CHIP_ESP32 selects no HAS_MPU, so the syscall classes have no one to protect, while an
# involuntary descent still has to FIT the stack it lands on. Its two stack=main classes are each
# core's KICKOS_LX6_CORE_STACK below _estack: MAIN the PRO_CPU's boot, CORE the APP_CPU's park and
# the doorbell interrupt it takes there.
#
# IDLE prices idle_entry's own frames, which sit above the interrupt idle waits for.
#
# at=<symbol> says the class prices an interrupt nested below that ONE callee alone: its depth is
# the longest path from a root that ends at the callee, the callee's own frame included, and a
# class none of whose roots reaches it is refused.
#
# stack=trap says the descent runs on a static kernel stack the arch owns. The SPAWN FLOOR
# clause does not apply.
#
# stack=panic says the descent is the panic reporter, on the array kickos_panic_stack_enter
# moves to, compared against KICKOS_PANIC_STACK_SIZE. No other class reaches it: the walk stops
# at that entry, which is assembly and has no .ci file to carry a call edge.
#
# stack=kernel says the descent runs on the interrupted thread's PER-THREAD KERNEL block, so
# frame plus depth is compared against KICKOS_KERNEL_STACK_SIZE less its canary word, and both
# halves drop where KICKOS_KERNEL_STACKS is 0.
#
# stack=idle says the descent runs on idle's own stack, the one privileged thread's, so frame plus
# depth is compared against KICKOS_IDLE_STACK_SIZE.
#
# stack=main says the descent is a stack a core boots on and every interrupt it takes nests on,
# so frame plus depth is compared against that stack: the one the image links, read out of its
# link maps as the __kickos_kernel_stack_start/_end span, or, where the class names size=, the
# macro that reserves it, resolved as frame= and depth= are. Its levels, in declaration order,
# are the steps one nest can take, each above the one before it: every root names its level, the
# depth is the deepest root of each level SUMMED, and a level whose roots are all absent is
# refused. The five stack= markers are exclusive.
#
# core=secondary says the stack=main class is the one a released secondary core parks on, which
# an image whose KICKOS_NUM_CORES is 1 does not have: there the class is printed as not measured
# and none of its roots is looked up.
#
# A table record names a vector table every linked image carries, read through its sized
# symbol; '?' where only some link it, first= the words before its first handler, prefix= what
# the toolchain puts before a C name. Every handler a table holds must be a root of the arch's
# one stack=main class, or carry a vector record: the level whose roots it reaches, or NONE when
# it calls nothing. An init record names the bounds of the constructor array the reset handler
# walks on a stack=main class's stack: every function it holds must be one a stack=main walk
# reaches, which is the binding of the reset handler's indirect site.
#
# kstacks=<n> says the class belongs to ONE of the two entry designs an arch can compile, the
# one KICKOS_KERNEL_STACKS selects at <n>. Where the knob disagrees the image does not contain
# the path, so check_trap_redzone.sh measures the class, PRINTS that it is not enforcing it, and
# drops both halves. Only armv7m needs it; every other arch static_asserts
# KICKOS_KERNEL_STACKS != 0.

# --- rv32imac ------------------------------------------------------------------
# Two registers separate the trap classes, both readable before the frame is built. mcause
# picks the entry: the .Lintr arms take TRAP, msip takes SWITCH, an ecall takes SYS, and any
# other exception takes FAULT. mstatus.MPP then picks the stack: an ecall from U-mode is SYS on
# the thread's kernel block, and every M-mode cause that is not msip is NESTED on the kernel's
# own trap stack. Idle, the one M-mode thread, makes no ecall.
#
# FAULT is the accepted U-mode fault: .Lfault runs the reporter with sp on the frame the entry
# built, which is the kernel block, so the whole dump chain lands there.
#
# SWITCH must not be deleted: .Lswitch and arch_start call kickos_arch_mpu_commit with sp =
# incoming->sp, the incoming thread's kernel block or idle's stack, and the SYS requirement and
# idle's floor both add this figure.
#
# MAIN is the stack boot runs on, _kernel_stack_size below _estack, which no trap shares.
arch    rv32imac header=arch/riscv/rv32imac/include/kickos/arch/rv_trap_stack.h

# The symbols the .Lintr arms of switch.S branch to.
root    rv32imac TRAP kickos_isr_timer
root    rv32imac TRAP kickos_rv_dispatch_soft
root    rv32imac TRAP kickos_rv_ext_dispatch
root    rv32imac TRAP kickos_rv_ext_dispatch_dev
root    rv32imac TRAP ?kickos_c6_amp_doorbell_service
# Called from the prologue/epilogue itself, on the same stack, so charged to every class.
root    rv32imac TRAP kickos_arch_mpu_commit
root    rv32imac TRAP ?kickos_trace_switch_done

# .Lecall_slow mrets into svc_trampoline, which calls syscall_dispatch; .Lecall calls
# kickos_ipc_fastpath inline, and the taken fastpath runs the same hooks.
root    rv32imac SYS  syscall_dispatch
root    rv32imac SYS  kickos_ipc_fastpath
root    rv32imac SYS  kickos_arch_mpu_commit
root    rv32imac SYS  ?kickos_trace_switch_done


# .Lfault, for a U-mode fault the entry ACCEPTED: the reporter and the stack-top query run on
# the frame the entry built, which is the kernel block. This charges the deeper of the kill and
# panic paths, so no claim about C control flow is needed.
root    rv32imac FAULT kickos_rv_fault_report
root    rv32imac FAULT kickos_fault_stack_top

# EXITK is the fault and slay stubs on the thread's own KERNEL BLOCK: .Lfault relocates sp to
# kickos_fault_stack_top, which answers with ctx.kernel_sp, and arch_ctx_redirect rebuilds the
# slay frame at that same top. The frame term is the msip frame: the stubs reschedule, and an
# msip trap from M-mode keeps its frame on the interrupted sp.
root    rv32imac EXITK kickos_thread_fault_exit
root    rv32imac EXITK kickos_thread_slay_exit
root    rv32imac IDLE  kmain.cc:idle_entry

# What .Lswitch itself calls, below the frame it just saved.
root    rv32imac SWITCH kickos_arch_mpu_commit
root    rv32imac SWITCH ?kickos_trace_switch_done

# The four .Lintr arms again, an M-mode entry running them on the trap stack instead, plus
# .Lfault's reporter. kickos_arch_mpu_commit is NOT here: .Lswitch and .Lecall are its only
# callers and neither is a nested path.
root    rv32imac NESTED kickos_isr_timer
root    rv32imac NESTED kickos_rv_dispatch_soft
root    rv32imac NESTED kickos_rv_ext_dispatch
root    rv32imac NESTED kickos_rv_ext_dispatch_dev
root    rv32imac NESTED ?kickos_c6_amp_doorbell_service
root    rv32imac NESTED kickos_rv_fault_report
root    rv32imac NESTED kickos_fault_stack_top
# .Ltrap_wild's containment call. A U-MODE entry and not a nested M-mode trap, so it is here
# for the STACK and not the cause: sp is the trap top at that label, which is the one this
# class measures. kickos_arch_mpu_commit below it is charged to SWITCH instead, the containment
# moving sp onto the incoming frame before that call exactly as .Lswitch does.
root    rv32imac NESTED kickos_rv_contain_wild_sp
# .Lland, where all four switch sites land: sp moves to the trap top first, so here for the
# stack as well.
root    rv32imac NESTED kickos_switch_landed

# The reporter, on its own array: kickos_panic_stack_enter is switch.S, so this root is the only
# way into the console tail.
root    rv32imac PANIC kickos_panic_report
level   rv32imac MAIN boot reason: Reset_Handler, the chip's startup.S calling it on _estack with mstatus.MIE clear, which nothing sets before arch_start's mret leaves this stack. No trap nests on it: an M-mode exception takes the trap stack, and the msip and ecall frames that stay on the interrupted sp need MIE or a privileged thread
root    rv32imac MAIN Reset_Handler level=boot
init    rv32imac __init_array_start __init_array_end reason: Reset_Handler@1/1 is bound NONE
unsized rv32imac arch_start 0 reason: switch.S, moves sp onto the first thread's frame before it writes anything; the hooks it calls run there and on the trap stack, which SWITCH and NESTED price
exclude rv32imac console_chip_writer_leave class=PANIC reason: a panic stores PANICKED before it prints, nothing leaves PANICKED, and a PANICKED writer is not counted, so no line of the panic leaves the bracket
exclude rv32imac ?console.cc:line_wake class=PANIC reason: the line state is written only by a KERNEL_OWNED or RECLAIMED line, and a panic stores PANICKED before it prints, so no line of the panic wakes a writer parked on that state

# Assembly and libgcc bodies have no .ci entry, so their frames are declared here. riscv gcc
# reports 0 bytes (static) for a frameless leaf too, so 0 is the graph's own unit and no
# return-address slot is added. Re-derive with riscv32-none-elf-objdump -d --disassemble=<sym>.
unsized rv32imac __udivdi3 0 reason: measured from the ELF, frameless register-only leaf
unsized rv32imac __umoddi3 0 reason: measured from the ELF, frameless register-only leaf
unsized rv32imac __clzsi2  0 reason: measured from the ELF, frameless register-only leaf
unsized rv32imac kickos_panic_stack_enter 0 reason: switch.S, three instructions that write no stack; jal leaves the return address in ra and the body never spills it
unsized rv32imac __divdi3  0 reason: measured from libgcc.a for this multilib, frameless register-only leaf: its body touches sp nowhere and ends in a bare ret, exactly as the two above.
unsized rv32imac __moddi3  0 reason: measured from the rv32imac libgcc.a disassembly, register-only body with no sp access

# --- rxv3 ----------------------------------------------------------------------
# PENDSW is the deferred-switch vector (INTB[27]); the syscall trap then splits,
# kickos_rx_syscall_trap's `cmp #56, r1` picking between a generic arm that lays the return

# --- armv7m --------------------------------------------------------------------
# THREE classes, two of them the same dispatch under the two entry designs this arch compiles.
# KICKOS_KERNEL_STACKS picks which one an image links: at 1 svc_trampoline starts on the
# calling thread's own kernel block, so the dispatch is SVCK,
# stack=kernel; at 0 it runs the dispatch on the caller's own PSP and the dispatch is SVC, on
# the thread stack. armv7m_trap_stack.h says which chips take which.
#
# Both classes are measured on every preset and only one is enforced on any given one. The call
# graph cannot say which design an object linked; the gate reads KICKOS_KERNEL_STACKS out of the
# board config it just generated, which is what the kstacks=0 marker on SVC and stack=kernel on
# SVCK are spent on.
#
# The SVC class is what the SPAWN FLOOR clause binds. PENDSV takes FRAME_MAX, its own worst-case
# push, and is the same under both designs and therefore unmarked, handler mode putting
# everything it calls on the MSP.
arch    armv7m header=arch/arm/armv7m/include/kickos/arch/armv7m_trap_stack.h

root    armv7m PENDSV NONE reason: PendSV_Handler runs in handler mode, where ARMv7-M forces SP_main, so everything it calls descends on the MSP and MSP measures it.

# svc_trampoline's only call, and the SAME ROOT SET serves both classes: what differs is which
# stack the descent lands on. The fastpath is reached with lr still an EXC_RETURN, in handler
# mode, on the MSP, so it roots neither.
root    armv7m SVC    syscall_dispatch
root    armv7m SVCK   syscall_dispatch

# The two stubs that relocate, on the block.
root    armv7m EXITK  kickos_thread_fault_exit
root    armv7m EXITK  kickos_thread_slay_exit
# The same two on the thread stack, where no block is seated to move them to.
root    armv7m EXIT   kickos_thread_fault_exit
root    armv7m EXIT   kickos_thread_slay_exit

# The reporter, on its own array: kickos_panic_stack_enter is switch.S, so this root is the only
# way into the console tail.
root    armv7m PANIC  kickos_panic_report
exclude armv7m console_chip_writer_leave class=PANIC reason: a panic stores PANICKED before it prints, nothing leaves PANICKED, and a PANICKED writer is not counted, so no line of the panic leaves the bracket
exclude armv7m ?console.cc:line_wake class=PANIC reason: the line state is written only by a KERNEL_OWNED or RECLAIMED line, and a panic stores PANICKED before it prints, so no line of the panic wakes a writer parked on that state
unsized armv7m kickos_panic_stack_enter 0 reason: switch.S, a limit write and an SP move that write no stack; bl leaves the return address in LR and the body never spills it
unsized armv7m kickos_rp_rom_call 24 reason: rp2xxx/rom_call.S, push {r4-r8,lr} under KICKOS_HAVE_STACK_LIMIT, which rp2350, the one armv7m chip that assembles it, sets; the bootrom routine it calls runs on kickos_rp_rom_stack, which no class measures
unsized armv7m _ZN6kickos6rp2xxx9wait_maskEjm 0 reason: measured from the ELF, a same-address alias of rp2xxx clocktree::wait, so 0 is its own frame and the edge below it carries the real cost
asmcall armv7m kickos_splim_plant reason: switch.S under KICKOS_SPLIM_PLANT_KBLOCK, a deliberate overflow of the kernel block that only check_splim_plant.sh's own scratch tree compiles (arch/CMakeLists.txt refuses it anywhere else), so no image this gate measures makes the call

root    armv7m IDLE   kmain.cc:idle_entry
