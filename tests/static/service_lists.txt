# Every kickos_services_* provider in this tree, and ONE configure preset that compiles
# it. tests/static/check_service_lists.sh reads this and refuses a provider that is not
# here.
#
#   <provider>  <preset>  <default|select>
#
# default = that preset's BOARD names this provider as its KICKOS_SERVICE_LIST default
#           in Kconfig, so configuring the preset both compiles it and links it into
#           every image.
# select  = no board defaults to it. Configuring the preset COMPILES it (the provider is
#           an ordinary target under its chip's branch of system/CMakeLists.txt and is in
#           `all`), but reaching an IMAGE needs -DKICKOS_SERVICE_LIST=<provider>.
#
# The preset is not free choice: a provider's source lives under system/init/<board>/, and
# the gate requires the declared preset to be a preset OF THAT BOARD. Only
# system/init/common/ is universal, which is what lets kickos_services_none name any preset.
# That provider is declared like the rest: it is the default on every board that ships no
# service list, so it is the one most images actually link.
#
# WHY THIS FILE EXISTS. An axis whose values are never all exercised makes "not covered"
# and "covered and passing" indistinguishable, and a provider nothing names is one whose
# compile failure surfaces on a bench pass months later.

# --- the universal default ---------------------------------------------------
kickos_services_none                microbit            default

# --- mk64f (frdmk64f) --------------------------------------------------------
kickos_services_frdmk64f            frdmk64f            default
kickos_services_frdmk64f_uartirq    frdmk64f            select

# --- xmc4800 (xmc4800-relax) -------------------------------------------------
kickos_services_xmc4800relax        xmc4800-relax       default
kickos_services_xmc4800relax_console xmc4800-relax      select
kickos_services_xmc4800relax_uartirq xmc4800-relax      select
