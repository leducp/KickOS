# Declarations for tests/static/app_stack.py, which check_trap_redzone.sh runs over its own
# scratch tree: WHICH application threads are bounded, on WHAT stack, and what the arch's trap
# entry reserves below each one's deepest sp.
#
#   need    <arch> header=<path> frame=<MACRO> zone=<MACRO> [via=<symbol>] reason: <text>
#   thread  <arch> <image> <name> root=<symbol> stack=<MACRO> reason: <text>
#   unsized <arch> <symbol> <bytes> [calls=[?]<symbol>[,...]] reason: <text>
#
# A thread passes when its root's longest path, plus frame, plus zone, fits the stack less the
# image's __kickos_tls_carve. The walk covers the units the image's link map LOADs and nothing
# else, and it refuses what it cannot bound instead of charging it nothing: a reachable node
# with no frame and no unsized record, an indirect call, a dynamic stack object, a cycle.
#
# via= is the function every thread's entry is called from, whose own frame stands below the
# root's for the thread's life: kickos_task_start on a translating arch. Only its frame is
# charged; the startup it runs first returns before the entry and is the stack floor's.
#
# stack= is a macro of the unit that defines the root, and the spawn has to pass exactly it.
# Every macro resolves under that unit's own compile command, ISA flags included. A thread is
# bounded on every trap_redzone tree of its arch that links its image's map, and an arch whose
# tree links an image another arch bounds fails until it declares that thread too. A token
# after a record's fixed fields that is no key its kind takes fails the parse.
#
# NO ARCH CATCHES A USER STACK OVERFLOW IN HARDWARE, so every one is bounded here. armv8a,
# rv64imac and x86_64 enter from user mode onto the thread's kernel block, but only a stack the
# kernel allocates has an unmapped page below it (kernel/include/kickos/ustack.h): a spawn naming
# its own stack is admitted on any range granted R|W in the child's space
# (syscall_thread.cc spawn_stack_admit), and the thread-local block is carved off the low end of
# every stack (kernel/include/kickos/tls.h), so an overrun corrupts before it can fault.
#
# ONLY A THREAD WHOSE WHOLE GRAPH CLOSES CAN BE DECLARED. Prebuilt newlib and libstdc++ carry
# no .ci, so a call into them is an unsized node, and the ones a thread reaches through a
# function pointer (exit's atexit handlers, stdio's FILE hooks) cannot be sized from here at
# all. That keeps out every program's main: it ends in exit.

# --- armv7m ------------------------------------------------------------------------------
need    armv7m header=arch/arm/armv7m/include/kickos/arch/armv7m_trap_stack.h \
               frame=KICKOS_ARMV7M_TRAP_ENTRY_FRAME zone=KICKOS_ARMV7M_TRAP_NEED_SVC \
               reason: the SVC guard's red zone below the validated PSP and the entry frame above it, which dominate a preemption's frame and the PendSV push at every posture
thread  armv7m reclaimwit       rwsink root=kickos_driver_task stack=KICKOS_USER_STACK_SIZE above=kickos_task_entry,kickos_task_enter \
               reason: the declared console driver, from its task's entry through its start and bring-up to its service body, on the stack the kernel gives a driver's entry
thread  armv7m reclaimwit_drain rwsink root=kickos_driver_task stack=KICKOS_USER_STACK_SIZE above=kickos_task_entry,kickos_task_enter \
               reason: the declared console driver, from its task's entry through its start and bring-up to its service body, on the stack the kernel gives a driver's entry
unsized armv7m arch_syscall 0 reason: syscall.S, a load, the svc and bx lr, which write no stack
unsized armv7m arch_syscall64 0 reason: syscall.S, the same entry as arch_syscall
unsized armv7m kickos_user_cas 0 reason: user_cas.S, an exclusive load, a compare and a store exclusive, which push nothing
unsized armv7m _free_r 64 calls=__retarget_lock_acquire_recursive,__retarget_lock_release_recursive,_sbrk,__wrap_sysconf \
               reason: measured on every armv7m multilib of the toolchain's libc.a. Nano's is push {r4, lr} then sp lowered by 8; full newlib's stmdb of six registers is 24, and its _malloc_trim_r pushes six more, calling sysconf and _sbrk_r, whose push of four calls _sbrk: 64. __malloc_lock and __malloc_unlock branch to the hooks with no frame
unsized armv7m __errno 8 calls=__getreent reason: measured on the toolchain's libc.a, push {r3, lr} and a call to __getreent, on every armv7m multilib

# level-1 interrupt builds its frame and runs its dispatch on whatever stack it interrupts.

               frame=KICKOS_LX6_TRAP_FRAME zone=KICKOS_LX6_TRAP_DEPTH \
